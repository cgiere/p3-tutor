# Misconception corrected: a model does not remember earlier conversations on its own

Riley believed that language models remember earlier conversations automatically, so the makerspace assistant would recall what each student said last week.
Corrected in chat: the model only sees the text it is given in each call, so anything it should "remember" has to be saved by the program and put back into the input.

**Evidence:** Riley's message in the session after quiz 0001 stated the misconception ("remember earlier conversations on their own").

**Implications:** Builds directly on record 0001. Next lesson: context window, tokens and cost, then memory design (what to save per student, what to reload). Check with a short question that Riley can say what the program must do.
