# Open misconceptions: the model runs tools itself (M4) and remembers across sessions (M3)

In quiz 0001 (s1), Riley understood the loop, the step-limit safeguard and that tools are chosen from their descriptions. Riley also said the model reads the booking system and "runs the 3 tools itself" in one call (M4), and that it remembers earlier sessions on its own (M3).
Future lessons should show the program, not the model, running each tool, with every step a separate model call, and that memory has to be supplied by the program.

**Evidence:** quiz 0001, submission s1, items q2, q4 and q6 (correct on q1 and q3, partial on q5).

**Implications:** Teach context and memory by showing what is in the model's input at each call. Retest M4 and M3 afterwards; s2 is spaced practice on the same quiz.
