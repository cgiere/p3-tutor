# Riley still blurs who runs a tool, and needs a stopping condition

On the spaced retake of quiz 0001, Riley correctly said the model only writes a tool request (q2) and that the result goes back as the model's next input (q5). The old belief that the model runs the tools itself (M4) still showed in the reasoning for q4, and M6 (an agent left running will eventually succeed) showed in q3, which was right on the first attempt.

**Evidence:** quiz 0001, submission s2, items q2, q3, q4, q6 (compared with s1).

**Implications:** Do not build on M4 or M6 as fixed. Before the lesson on context and memory, have Riley label each step of a request "model writes" or "program runs", and ask what stops the loop. In tool-description work, stress that the model chooses from the whole description, not the name alone.
