# Agent Architecture Resources

## Knowledge

- [Article: "Effective context engineering for AI agents" (Anthropic Engineering)](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents)
  Context as a finite resource, context rot, just-in-time retrieval, compaction, note-taking and sub-agents. Use for: anything about what goes in the context and how to keep it small.
- [Docs: LangChain, memory concepts](https://docs.langchain.com/oss/python/concepts/memory)
  Short-term (thread) versus long-term (cross-session) memory and how stores are organised. Use for: the vocabulary and structure of agent memory in Python.
- [Blog: "Context management" (Claude)](https://claude.com/blog/context-management)
  Context editing and the memory tool for long-running agents. Use for: how clearing old tool results and file-based memory work in practice.
