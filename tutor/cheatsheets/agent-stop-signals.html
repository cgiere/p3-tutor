Agent stop signals

Three layers decide "done": the model (no tool call), limits (cut off, done or not), checks (can refuse the stop).

while response.stop_reason == "tool_use":
    run tools, send tool_result, call again
# any other stop_reason exits: decide what it means

Claude API stop_reason

ValueMeaningDone?
tool_useWaiting on a tool you runNo, keep looping
end_turnModel finished naturallyModel believes so; verify
max_tokensHit output token limitNo, truncated
pause_turnServer tool loop hit its cap (default 10)No, send back to continue
stop_sequenceHit one of your stop sequencesDepends on your sequence
refusalModel declinedNo
